## Εργαστηριακή Άσκηση 0: Εισαγωγή στη Γραμμή Εντολών (CLI) & Βασικές Εντολές Δικτύου

### Στόχοι της Άσκησης

Με την ολοκλήρωση της παρούσας εργαστηριακής συνεδρίας, οι φοιτητές/σπουδαστές αναμένεται να:

1. Εξοικειωθούν με το περιβάλλον διεπαφής γραμμής εντολών (CLI) και τη βασική σύνταξη εντολών.
2. Κατανοήσουν σε βάθος την πλοήγηση μέσω απόλυτων και σχετικών διαδρομών (`cd`, `cd ..`, `cd ../..`, `cd -`).
3. Εφαρμόζουν προχωρημένες παραμέτρους και μοτίβα αναζήτησης με την εντολή απαρίθμησης `ls` (`-lh`, `-lt`, `-R`, `*`).
4. Εφαρμόζουν τεχνικές ανακατεύθυνσης εξόδου και διασωλήνωσης (pipes).
5. Διαχειρίζονται τα δικαιώματα προσπέλασης αρχείων μέσω συμβολικών και αριθμητικών παραμέτρων.
6. Ελέγχουν και αναλύουν βασικές ρυθμίσεις και παραμέτρους συνδεσιμότητας δικτύου (`ifconfig`, `ip`, `ping`, `ss`, `nslookup`).

## Εκτεταμένα Παραδείγματα Πλοήγησης με `cd` (Σχετικές & Απόλυτες Διαδρομές)

Η εντολή `cd` (*Change Directory*) επιτρέπει τη μετακίνηση στο ιεραρχικό δέντρο καταλόγων.

1. **Μετάβαση σε βαθύτερο υποφάκελο (Σχετική διαδρομή):**
   ```bash
   cd project/src
   pwd
   # Αποτέλεσμα: /home/user/lab1_workspace/project/src
   ```

2. **Ανέβασμα κατά ένα επίπεδο (`..`):**
   ```bash
   cd ..
   pwd
   # Βρίσκεστε πλέον στο: /home/user/lab1_workspace/project
   ```

3. **Ανέβασμα κατά πολλαπλά επίπεδα ιεραρχίας ταυτόχρονα (`../..`):**
   ```bash
   # Από το project/src/ μεταβείτε κατευθείαν δύο επίπεδα επάνω
   cd src
   cd ../..
   pwd
   # Βρίσκεστε πίσω στον ριζικό φάκελο της άσκησης: lab1_workspace
   ```

4. **Εναλλαγή στον αμέσως προηγούμενο κατάλογο (`cd -`):**
   Η παράμετρος `-` επιστρέφει αυτόματα στον κατάλογο όπου βρισκόσασταν πριν την τελευταία αλλαγή:
   ```bash
   cd project/build
   cd -
   # Επιστροφή στο lab1_workspace
   cd -
   # Επιστροφή στο project/build
   ```

5. **Μετάβαση στον προσωπικό κατάλογο χρήστη (`cd ~` ή `cd`):**
   ```bash
   cd ~
   pwd
   # Επιστροφή στον φάκελο εργασίας της άσκησης μέσω σχετικής διαδρομής:
   cd lab1_workspace
   ```

6. **Μετάβαση σε αδελφό κατάλογο μέσω σχετικής διαδρομής:**
   Μεταβείτε από το `project/docs/` στο `backup/` χωρίς να περάσετε πρώτα από το root:
   ```bash
   cd project/docs
   cd ../../backup
   pwd
   # Βρίσκεστε στο: lab1_workspace/backup
   cd ..
   ```

#### Βήμα 1.3: Αναλυτική Χρήση και Παράμετροι της Εντολής `ls`

Η εντολή `ls` (*List*) εμφανίζει τα περιεχόμενα ενός καταλόγου. Οι διαφορετικές σημαίες (flags) τροποποιούν τις παρεχόμενες λεπτομέρειες.

1. **Δημιουργία δοκιμαστικών αρχείων για παρατήρηση:**
   ```bash
   cd lab1_workspace/project/src
   touch main.c utils.c config.h .env_secret
   echo "Linux CLI Lab" > notes.txt
   ```

2. **Απλή προβολή έναντι αναλυτικής λίστας (`ls` vs `ls -l`):**
   ```bash
   ls
   ls -l
   ```
   *Παρατηρήστε τα 7 πεδία της αναλυτικής προβολής: τύπος αρχείου/δικαιώματα, αριθμός δεσμών, ιδιοκτήτης, ομάδα, μέγεθος σε bytes, χρονοσφραγίδα τροποποίησης, όνομα.*

3. **Εμφάνιση κρυφών αρχείων (`ls -a` και `ls -la`):**
   Στο Linux, τα αρχεία των οποίων το όνομα ξεκινά με τελεία (`.`) είναι κρυφά:
   ```bash
   ls -la
   ```
   *Εντοπίστε τα αρχεία `.`, `..` και το κρυφό `.env_secret`.*

4. **Ανάγνωση μεγέθους σε αναγνώσιμη μορφή (`ls -lh`):**
   Η παράμετρος `-h` (*human-readable*) μετατρέπει τα bytes σε K, M, G:
   ```bash
   ls -lh
   ```

5. **Ταξινόμηση βάσει χρόνου τροποποίησης (`ls -lt` και `ls -ltr`):**
   * `ls -lt`: Ταξινόμηση από το πιο πρόσφατο στο παλαιότερο.
   * `ls -ltr`: Αντίστροφη ταξινόμηση (τα πιο πρόσφατα αρχεία εμφανίζονται στο τέλος της οθόνης):
   ```bash
   ls -ltr
   ```

6. **Αναδρομική προβολή υποκαταλόγων (`ls -R`):**
   Εμφανίζει όλα τα περιεχόμενα όλων των υποφακέλων σε δενδροειδή μορφή:
   ```bash
   cd ../..
   ls -R lab1_workspace
   ```

7. **Φιλτράρισμα με χαρακτήρες μπαλαντέρ (Wildcards / Globbing):**
   * Εμφάνιση μόνο των αρχείων με κατάληξη `.c`:
     ```bash
     ls lab1_workspace/project/src/*.c
     ```
   * Εμφάνιση αρχείων των οποίων το όνομα ξεκινά από `u`:
     ```bash
     ls lab1_workspace/project/src/u*
     ```

> **Ερώτημα 1.1:** Ποια είναι η διαφορά μεταξύ της εντολής `cd ..` και της εντολής `cd .`;  
> **Ερώτημα 1.2:** Ποιος συνδυασμός παραμέτρων της `ls` είναι προτιμότερος όταν αναζητάτε ποιο αρχείο τροποποιήθηκε τελευταίο σε έναν κατάλογο με εκατοντάδες αρχεία;

### Μέρος Β: Φιλτράρισμα Δεδομένων και Διασωλήνωση (Pipelines)

#### Βήμα 2.1: Χρήση `grep` και Ανακατεύθυνση

Αναζητήστε πληροφορίες για τον επεξεργαστή από το εικονικό σύστημα αρχείων `/proc`:
```bash
grep "model name" /proc/cpuinfo > cpu_spec.txt
head -n 2 cpu_spec.txt
```

#### Βήμα 2.2: Διασωλήνωση (Pipeline)

Καταμετρήστε το πλήθος των ενεργών διεργασιών του συστήματος συνδυάζοντας την εντολή `ps` με την εντολή καταμέτρησης `wc`:
```bash
ps aux | wc -l
```

> **Ερώτημα 2.1:** Ποιος είναι ο ρόλος του χαρακτήρα διασωλήνωσης `|` (pipe) στη ροή δεδομένων μεταξύ δύο εντολών;

### Μέρος Γ: Βασικές Εντολές Ελέγχου Δικτύου

#### Βήμα 3.1: Έλεγχος Διασυνδέσεων Δικτύου (`ifconfig` / `ip`)

1. Εμφανίστε τις διαθέσιμες διεπαφές δικτύου και τις αντιστοιχισμένες διευθύνσεις IP:
   ```bash
   ifconfig
   ```
   *(Σε περίπτωση που η εντολή `ifconfig` δεν είναι εγκατεστημένη στο σύστημα, εκτελέστε την εντολή `ip addr show`)*.

2. Εντοπίστε τη διεύθυνση IPv4 (`inet`) της κύριας διεπαφής (π.χ. `eth0`, `enp3s0` ή `wlan0`), καθώς και της τοπικής διεπαφής ανάδρασης (`lo`).

> **Ερώτημα 3.1:** Ποιος είναι ο ρόλος της διεπαφής `lo` (loopback) και ποια είναι η προεπιλεγμένη διεύθυνση IPv4 που της αντιστοιχεί;

#### Βήμα 3.2: Έλεγχος Συνδεσιμότητας με την Εντολή `ping`

1. Ελέγξτε τη λειτουργία της τοπικής στοίβας δικτύου:
   ```bash
   ping -c 3 127.0.0.1
   ```

2. Ελέγξτε τη συνδεσιμότητα με έναν εξωτερικό κόμβο (π.χ. διακομιστής DNS), αποστέλλοντας ακριβώς 4 πακέτα αίτησης ICMP:
   ```bash
   ping -c 4 8.8.8.8
   ```

> **Ερώτημα 3.2:** Καταγράψτε το ποσοστό απώλειας πακέτων (packet loss) και τη μέση τιμή χρόνου απόκρισης (average round-trip time - RTT) από την έξοδο του `ping`.

#### Βήμα 3.3: Ενεργές Συνδέσεις και Επίλυση Ονομάτων (`ss`, `nslookup`, `traceroute`)

1. Ελέγξτε τις ανοικτές και ακροώμενες θύρες TCP/UDP του συστήματός σας:
   ```bash
   ss -tuln
   # Εναλλακτική παραδοσιακή εντολή: netstat -tuln
   ```

2. Εκτελέστε επίλυση ονόματος τομέα (DNS resolution) για έναν ιστότοπο:
   ```bash
   nslookup www.kernel.org
   ```

3. Ανιχνεύστε τα ενδιάμεσα δρομολογητικά άλματα (hops) μέχρι τον προορισμό:
   ```bash
   traceroute 8.8.8.8
   ```

### Μέρος Δ: Διαχείριση Δικαιωμάτων Αρχείων (`chmod`)

#### Βήμα 4.1: Τροποποίηση Δικαιωμάτων Εκτέλεσης

1. Δημιουργήστε ένα απλό αρχείο σεναρίου εντολών:
   ```bash
   echo 'echo "Σενάριο Εργαστηρίου Εκτελέστηκε Επιτυχώς"' > script.sh
   ```

2. Ελέγξτε τα αρχικά δικαιώματα προσπέλασης:
   ```bash
   ls -l script.sh
   ```

3. Προσθέστε δικαίωμα εκτέλεσης (`+x`) και εκτελέστε το:
   ```bash
   chmod +x script.sh
   ./script.sh
   ```

4. Ρυθμίστε τα δικαιώματα σε αριθμητική μορφή `755`:
   ```bash
   chmod 755 script.sh
   ```

> **Ερώτημα 4.1:** Αναλύστε τι δικαιώματα παρέχει η τιμή `755` για τον ιδιοκτήτη (owner), την ομάδα (group) και τους λοιπούς χρήστες (others).
